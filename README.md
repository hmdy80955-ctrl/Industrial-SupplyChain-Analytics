# Industrial Supply Chain & Procurement Analytics (SQL)

## Project Overview
This project demonstrates advanced financial and data analysis skills in manufacturing and supply chain management. It covers database design, total landed cost calculations (including shipping and custom duties), and dynamic sales integration to analyze net profit margins.

## Key Insights Delivered
* **Total Landed Cost Management:** Calculated true import costs by aggregating FOB unit prices, freight, and custom expenses.
* **Profitability Mapping:** Utilized `INNER JOIN` operations to connect procurement data with sales revenue, calculating exact net profits per raw material.
* **Executive Summary:** Integrated aggregation functions (`SUM`, `AVG`, `MAX`, `MIN`) to deliver high-level financial reporting for executive decision-making.

## Tech Stack
* **Database Engine:** MySQL
* **Concepts Used:** Data Aggregation, Multi-conditional Filtering (`AND`), Table Joins (`INNER JOIN`), Alias Naming (`AS`).
